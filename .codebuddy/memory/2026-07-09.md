- 根因：`drawAnnotation` 用了 `image.width/height`，但 `image` 仅是定义在 `renderAnnotations`(line 312 `const image = currentImage`) 里的局部变量，`drawAnnotation` 是同级函数访问不到。之前 0 标注所以不暴露；一旦有归一化 bbox（走 `ann.normalized` 分支）即崩。

## 18:30 悬停信息框 + 框上文字描述不显示

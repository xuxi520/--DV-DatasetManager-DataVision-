### 2. 重新设计多窗口对比功能

**用户真实需求**：
- 当前多窗口对比是加载同一数据集图片来对比里面不同的图片
- 真实需求：多窗口中每个窗口加载的是不同数据集，来渲染出不同数据集标签的结果来对比

**两种对比模式**：

#### 模式一：同图异标（Same Image, Different Labels）
- 同一批数据集图片
- 第一窗口加载渲染的是原标签
- 其他窗口只加载新标签渲染在同一批图片上
- 例如：同一批图片，第一个窗口显示原始标注，第二个窗口显示经过不同预处理逻辑得到的预标注标签

#### 模式二：异图异标（Different Images, Different Labels）
- 第一个窗口渲染的原数据图片与标签
- 其他窗口加载的是另外图片文件夹与另外标签文件
- 例如：完全不同的数据集，不同的图片和不同的标签

**实现方案**：

1. **创建新组件** `MultiDatasetCompare.vue`
   - 支持加载多个数据集
   - 支持两种对比模式切换
   - 每个窗口可以独立选择数据集和标注文件
   - 模式一：同步导航（所有窗口显示同一张图片）
   - 模式二：独立导航（每个窗口可以浏览自己的图片）

2. **数据结构设计**
   ```typescript
   interface CompareWindow {
     id: string
     name: string
     datasetId: string
     color: string
     currentImage?: ImageFile
     currentImageIndex: number
     annotations: ParsedAnnotation[]
   }
   ```

3. **UI 设计**
   - 顶部工具栏：视图模式、对比模式、缩放控制、同步导航开关
   - 窗口配置面板：配置每个窗口的数据集、标注文件
   - 对比内容区：网格/水平/垂直布局
   - 窗口底部导航：同步导航或独立导航

4. **更新 App.vue**
   - 将多窗口对比模式指向新的 `MultiDatasetCompare` 组件
   - 导入新的组件

**修改文件**：
- `src/components/MultiDatasetCompare.vue` (新建)
- `src/App.vue` (更新)

**技术要点**：
- 使用 `loadDatasetWithAnnotations` 加载数据集和标注
- 每个窗口存储独立的当前图片索引
- 模式一：切换图片时同步所有窗口
- 模式二：每个窗口独立导航

### 6. 网格模式布局修复（21:43 - 23:08）

**用户反馈的问题**：
1. 网格图片堆叠在一起（CSS 冲突导致）
2. el-pagination 的 `small` 属性废弃警告
3. 标注框显示像"胶囊"一样，高度异常
4. 分页翻页功能不工作

**修复过程**：

1. **第一次修复（21:43）**：
   - 删除重复的 `.grid-item-img` CSS 定义（被定义了两次导致冲突）
   - `el-pagination` 的 `small` 改为 `size="small"`
   - 为 `.grid-image` 添加 `position: absolute`

2. **第二次修复（23:08）**：
   - 根因：固定高度容器(200px) + `object-fit: cover/contain` 导致标注框百分比定位错误
   - 方案：改用动态 `aspect-ratio` 布局，每个网格项根据图片原始宽高比设置比例
   - 新增 `getGridItemRatio(file)` 函数计算宽高比
   - 添加 `@current-change="onPageChange"` 修复分页问题
   - 使用 `object-fit: contain` 确保图片完整显示

3. **第三次修复（23:15）**：
   - 问题：动态 `aspect-ratio` 导致网格项高度参差不齐（每张图片比例不同）
   - 方案：回退到**固定高度(180px) + `object-fit: cover`**方案
   - 移除 `:style="{ aspectRatio: getGridItemRatio(file) }"` 动态样式
   - `.grid-item-img` 设置固定 `height: 180px`
   - `.grid-image` 使用 `object-fit: cover` 确保填满容器
   - 标注框百分比定位在 cover 模式下能正确对应图片内容

**最终方案**：固定高度180px + object-fit: cover（图片可能有边缘裁剪，但网格整齐、标注框准确）

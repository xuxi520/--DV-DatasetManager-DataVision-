## 今天完成的工作

### 1. 修复缩略图只加载一部分的问题
- **问题**：列表中的缩略图只加载了前100张，后面的图片没有缩略图
- **原因**：`datasetService.ts` 第94-104行只生成前100张图片的缩略图
- **解决方案**：
  - 修改 `FileList.vue` 组件，实现懒加载缩略图功能
  - 添加 `thumbnailCache` 响应式对象缓存缩略图
  - 使用 `watch` 监听可见文件变化，只为可见文件生成缩略图
- **修改文件**：`src/components/FileList.vue`

### 2. 修复标注框没有显示置信度和描述信息的问题
- **问题**：标注框已正常渲染，但没有显示 json 中的置信度和文本描述信息
- **原因**：
  - `ParsedAnnotation` 类型缺少 `confidence` 和 `description` 字段
  - 解析器没有提取这些信息
  - 渲染器没有显示这些信息
- **解决方案**：
  - 更新 `ParsedAnnotation` 类型定义，添加 `confidence` 和 `description` 字段
  - 更新 `annotationParser.ts`，在解析 COCO 格式和通用 JSON 格式时提取这些信息
  - 更新 `ImageViewer.vue`，在绘制标注框标签时显示这些信息
- **修改文件**：
  - `src/annotationParser.ts`
  - `src/components/ImageViewer.vue`
- **效果**：标注框标签现在显示 `类别名称 置信度% | 描述信息`

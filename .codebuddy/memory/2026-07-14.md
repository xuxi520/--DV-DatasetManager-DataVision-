# 2026-07-14 工作日志

## BUG 修复：底部切换按钮只切单个窗口 → 改为同时切换所有窗口
- 现象：窗口下方的上一张/下一张按钮只切换「焦点窗格」，而原有的同步切换组仅当恰好 2 窗格才出现，导致多窗格时无法一次性整体翻页。
- 改动：
  - `useViewerState.ts`：删除 `prevFileSync`/`nextFileSync`（仅前两窗格）与 `dualCanPrev`/`dualCanNext`/`syncPrevActive`/`syncNextActive`，新增 `prevFileAll`/`nextFileAll`（遍历**所有**已选中文件的窗格各移一张）+ `allCanPrev`/`allCanNext`（任一窗格可移动即可用）。`prevFileActive`/`nextFileActive`（仅焦点窗格）保留供键盘导航 `handleKeydown` 使用。
  - `DatasetViewer.vue`：底部主按钮组改为调用 `prevFileAll`/`nextFileAll`，移除仅双窗格显示的同步组，新增「同步切换所有窗口」提示。
- 验证：`vue-tsc --noEmit` + lint 均 0 错误。
